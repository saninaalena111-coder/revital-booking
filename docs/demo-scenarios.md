# Демо-сценарии для презентации

Все сценарии есть в кнопке **«Демо-сценарии»** (справа внизу на любом экране).
Каждый шаг — ссылка, которая открывает экран сразу под нужной ролью (`?as=…`).
Перед показом нажмите **«Сбросить демо-данные»**.

Демо-«сегодня» — понедельник, 12 октября 2026, «сейчас» — 10:40.
Главная гостья — **Анна Смирнова**, номер 4-315 (корпус 4), 8–15 октября, «Базовая путёвка»,
аллергия на йод.

| № | Сценарий | Шаги | Что сказать |
|---|---|---|---|
| 1 | Гость записался с сайта | `/booking` → «Я сейчас проживаю» → любые телефон и фамилия → терапевт Орлова → время → подтвердить. Затем `/mis/today?as=doctor` | Запись сразу у врача с пометкой «С сайта». Система не предлагает время, когда у гостя процедура |
| 2 | Приём голосом и курс процедур | `/mis/today?as=doctor` → Ковалёва → «Начать приём» → нажать «Жалобы» → микрофон (или «Вставить пример диктовки») → диагноз «боль спина» → назначить грязевые аппликации → «Завершить приём» | Протокол собирается сам, врач не печатает |
| 3 | Раскладка без конфликтов | `/mis/patient?id=p-tarasov&tab=prescriptions&as=doctor` → процедура → «Подобрать время»; затем `/mis/rooms-schedule` | Учитываются кабинет, число мест, питание, приёмы врачей; конфликты — словами |
| 4 | Медсестра отмечает процедуру | `/mis/procedures?as=nurse` → «Выполнено»; затем `/cabinet?tab=course` | Одно нажатие — счётчик курса у гостя меняется сразу |
| 5 | Подпись и ЕГИСЗ | `/mis/egisz?as=doctor` → «Подписать» → QR → «Отправить в ЕГИСЗ» → через секунды «Зарегистрирован в РЭМД»; документ с ошибкой → «Исправить» | Облачная подпись врача и обмен через N3.Health в рабочей версии |
| 6 | Заселение по шахматке | `/mis/stays?as=reception` → «Заселить»; шахматка 14 / 30 дней, клик по клетке | Свободные номера и брони видно сразу, бронь — в один клик |
| 7 | Руководитель видит сеть | `/mis/analytics?as=manager`; затем `/mis/patients?as=marketer` | Загрузка и выручка по всем санаториям; маркетолог не видит медкарты |
| 8 | Помощник подсказывает | `/mis/today?as=doctor&ask=как оформить выписку` | Вопрос своими словами → шаги и кнопка «Открыть экран» |
| 9 | Глазами гостя | `/mis/patient?id=p-anna&as=doctor` → «Сформировать выписку» → «Подписать»; затем `/cabinet` и `/cabinet?tab=documents` | Гость видит расписание по дням и подписанную выписку |

## Дополнительно

- **Другой санаторий**: в навигаторе «Другой санаторий» или на экране входа «Как это выглядит
  для другого санатория» — МИС в фирменном стиле вымышленной сети «Сосновый Кров».
- **Онлайн-запись** (вкладка навигатора): 7 вопросов исходного прототипа — логика расписания,
  обмен данными с МИС, события об изменениях.
- **Телефон**: личный кабинет, процедурный кабинет и приём врача адаптированы под экран 375 px.

## Если что-то пошло не так

- Экран показывает старые данные после экспериментов — «Сбросить демо-данные».
- Не та роль — «Сменить роль» внизу меню или ссылка сценария с `?as=`.
- Браузер не распознаёт речь (Safari, Firefox) — кнопка «Вставить пример диктовки».
